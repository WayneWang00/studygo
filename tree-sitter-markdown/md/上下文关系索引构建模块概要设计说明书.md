# 1.**介绍**

## 1.1.**目的**

*简要介绍该设计要解决的问题（满足用户什么需求或者解决现有设计什么问题）。*

  诸葛神码后台上下文模块codebase-indexer提供了代码仓库语义检索、关系检索功能，用于支持对话、补全、code
reivew 三大核心功能。当前该模块存在如下问题：

（1）代码安全。客户端会定时将用户代码上传到服务端进行明文存储，存在较大的源码泄露隐患。

（2）索引构建存在失败情况。当前关系索引解析复用了scip，该工具对go、c
、cpp、java支持不好，依赖构建工具下载依赖，如果依赖下载失败，则索引也会失败。

（3）索引构建实时性不够。scip
每次会对代码仓库重新进行全量索引，针对大型仓库，每次都要数分钟时间才能完成。

上面问题可分为代码安全和索引构建两类。

本设计方案的目的在于解决这两类问题。
